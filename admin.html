Panel de la web

Entra con tu clave de GitHub para editar textos, fotos, carta, contacto y eventos.

¿Cómo consigo la clave?
  1. Entra en GitHub y abre crear un token (fine-grained).
  2. Ponle un nombre (por ejemplo Panel web) y una caducidad.
  3. En Repository access elige Only select repositories y marca solo el repositorio de la web.
  4. En Permissions → Repository permissions, pon Contents en Read and write.
  5. Pulsa Generate token, cópialo y pégalo aquí.

La clave solo se guarda en este navegador. No la compartas: quien la tenga puede cambiar la web.
